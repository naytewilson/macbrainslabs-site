HOW TO READ IT / 03

Evidence isn't a single badge.

Planner reported: Core ML's assigned compute unit, not a physical trace of the Neural Engine.

Measured: an observed result for a named model, device, compiler and method. It does not generalize automatically.

Field note: engineering interpretation, including counterexamples and failed hypotheses.

Verified archive: release provenance and file integrity. A DOI does not imply peer review or independent replication.
